# 💼 Experience

## 🏛️ AI/ML Project Intern
### Indian Institute of Technology Kharagpur
**May 2026 – July 2026**

- Building an anticipatory trip planning system under the **ANRF ARG grant**.
- Ingesting live news, RSS feeds, and traffic incident APIs to extract structured disruption events using an LLM pipeline.
- Designed an **LLM extraction pipeline using LangChain LCEL**, structured JSON output, Pydantic validation, and automatic retry.
- Implemented probabilistic route risk scoring using **severity × LLM confidence** across active disruptions mapped onto OSMnx road graphs.
- Integrated Google News RSS, NewsAPI, and TomTom Live Traffic Incidents with deduplication and pre/post-LLM filtering.
- Developed a real-time **FastAPI backend** with async background processing and a Leaflet.js frontend rendering route risk overlays within 2 seconds.

🔗 [GitHub Repository](https://github.com/Ruchi-Kumarii/traffic-ai)  
🔗 [Live Demo](https://traffic-ai-vszp.onrender.com/)
